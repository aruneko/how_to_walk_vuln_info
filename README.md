# 脆弱性情報の歩き方

セキュリティ・キャンプ2026ミニ（北海道開催）の講義資料です。
CVE / NVD・GHSA・OVAL・CSAF といった主要な脆弱性情報源の現状と読み方を学び、実際のデータを使って「自分たちのシステムに影響があるか」を判定する演習を行います。

## 対象

- Linux の基本操作と、何らかのプログラミング言語・パッケージマネージャの利用経験があること

## 到達目標

- 主要な脆弱性情報源（CVE / NVD、GHSA、OVAL、CSAF）の役割と違いを説明できる
- 脆弱性情報から影響を受ける製品・バージョン範囲を読み取れる
- 与えられた環境情報と照らし合わせて、影響の有無を判定できる
